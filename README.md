## Overview

Traceability Matrix is a pnpm workspace for requirements traceability. It contains an Express API, a Vite mockup sandbox, OpenAPI-generated Zod types, and GitHub Actions workflows that publish a weekly health report and scan retained repository surfaces for secrets.

## API server

The root `package.json` accepts pnpm only.

```bash
pnpm install
PORT=3000 pnpm --filter @workspace/api-server run dev
```

| Route | Description |
|-------|-------------|
| `GET /api/healthz` | Returns `{ "status": "ok" }` |

`PORT` is required. The server does not expose a separate index route.

## Mockup sandbox

```bash
pnpm --filter @workspace/mockup-sandbox run dev
```

## Repository checks

- **Repo Health Audit** refreshes `docs/health-report.md` on a weekly schedule. Pull requests run the report step and do not push a commit.
- **Full History Secret Audit** and **Publication PASS Gate** scan git history and the external surfaces GitHub still retains: release assets, Actions artifacts, Actions logs, and issue or pull request attachments. Objects GitHub has deleted are reported as unretained. A secret finding fails the check.
