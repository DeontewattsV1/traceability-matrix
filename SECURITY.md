# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |

Security fixes are applied on the `main` branch. There are no other supported release lines.

## Reporting a vulnerability

Report security issues privately to [deonte@goodshyt.fun](mailto:deonte@goodshyt.fun). Include a description, the affected path or workflow, and steps to reproduce when you have them.

Please do not open a public issue for an undisclosed vulnerability.

You will receive an acknowledgement within 7 days. Allow a reasonable window for a fix before any public disclosure.
